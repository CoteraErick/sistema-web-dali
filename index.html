Bienvenidos a la Tienda D'Ali

La Tienda D'Ali es un establecimiento comercial dedicado a la venta de viveres y productos de consumo diario.

Este sitio web es un prototipo academico que representa las principales secciones de un sistema de ventas e inventario.

Problematica identificada

Actualmente, el negocio realiza diferentes actividades de registro de ventas y control de inventario de manera manual.

Esta situacion puede generar dificultades para conocer las cantidades disponibles, organizar los productos y consultar la informacion de las ventas.

Objetivos del sitio web

  1. Presentar informacion del negocio.
  2. Mostrar los productos disponibles.
  3. Representar el control de inventario.
  4. Mostrar un formulario de ventas.
  5. Presentar reportes de ejemplo.

Secciones del sistema

  • Productos:Consulta del catalogo de productos.
  • Inventario:Visualizacion de existencias y formulario de registro de productos.
  • Ventas:Formulario de demostracion para registrar informacion de una venta.
  • Reportes:Visualizacion de datos de ejemplo organizados en tablas.
