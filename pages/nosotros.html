¿Quienes somos?

La Tienda D'Ali es un establecimiento comercial dedicado a la venta de viveres y productos de consumo diario.

El negocio realiza actividades relacionadas con la comercializacion de productos, el registro de ventas y el control de las existencias disponibles.

Nuestro proyecto: Desarrollar un prototipo de sitio web que permita representar de manera organizada los procesos principales de ventas e inventario.

Situacion actual del negocio

Actualmente, la Tienda D'Ali realiza gran parte del registro de ventas y del control de inventario de manera manual.

La disponibilidad de los productos se comprueba mediante revisiones fisicas, lo que puede dificultar la organizacion y actualizacion de la informacion.

Problemas identificados

Durante el levantamiento de requisitos se identificaron las siguientes dificultades:

  • Registro manual de ventas.
  • Dificultad para controlar el inventario.
  • Desorganizacion de productos.
  • Dificultad para conocer las cantidades disponibles.
  • Perdida de tiempo al buscar informacion de productos.

Propuesta de solucion

Se propone elaborar un prototipo de sitio web para representar las principales funciones de un sistema de ventas e inventario.

El sitio web incluira paginas para visualizar productos, consultar existencias de ejemplo, presentar formularios y mostrar reportes de demostracion.

Objetivos del proyecto

  1. Organizar visualmente la informacion del negocio.
  2. Presentar un catalogo de productos.
  3. Representar el control de inventario.
  4. Diseñar un formulario de ventas.
  5. Mostrar reportes mediante tablas HTML.

Usuarios del sistema propuesto

El sistema completo esta pensado principalmente para dos tipos de usuarios:

  • Administrador: responsable de supervisar las operaciones y administrar productos.
  • Empleado: personal encargado de apoyar las actividades de ventas e inventario.
