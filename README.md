
# Sistema Web para la Tienda D'Ali

## 1. Descripción del proyecto

El proyecto consiste en el desarrollo de un prototipo
de sitio web para la Tienda D'Ali, establecimiento
dedicado a la comercialización de víveres y
productos de consumo diario.

La propuesta surge de la necesidad de mejorar
la organización de los productos, el control
del inventario y el registro de ventas.

El sitio web fue desarrollado con HTML,
utilizando los conocimientos adquiridos
en la asignatura Fundamentos de Sistemas Web.

## 2. Objetivo general

Desarrollar un prototipo de sitio web para
representar los principales procesos de
gestión de productos, ventas e inventario
de la Tienda D'Ali, aplicando técnicas de
versionamiento mediante Git y GitHub.

## 3. Tecnologías utilizadas

- HTML5: estructura de las páginas web.
- Git: control de versiones.
- GitHub: repositorio remoto.
- Visual Studio Code: edición del código.

## 4. Funcionalidades implementadas

### Página de inicio
Presenta la información general del proyecto
y el menú de navegación.

### Nosotros
Describe el establecimiento, su problemática
y los objetivos del proyecto.

### Productos
Presenta un catálogo de productos de ejemplo
organizado mediante tablas HTML.

### Inventario
Muestra existencias de demostración e incluye
un formulario para ingresar datos de productos.

### Ventas
Presenta un formulario para representar
el registro de una venta.

### Reportes
Muestra tablas de reportes con información
ficticia sobre ventas y productos.

## 5. Estructura del proyecto

- index.html: página principal.
- nosotros.html: información del negocio.
- productos.html: catálogo de productos.
- inventario.html: control de inventario.
- ventas.html: formulario de ventas.
- reportes.html: reportes de ejemplo.
- README.md: documentación del proyecto.

## 6. Organización de las ramas

- main: versión final aprobada.
- desarrollo: integración de funcionalidades.
- pruebas: validación del sitio web.
- feature-erick: desarrollo individual.

## 7. Comandos Git utilizados

- git init
- git branch
- git switch
- git add
- git commit
- git push
- git pull
- git merge
- git status
- git log
- git remote -v

## 8. Instrucciones de ejecución

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo index.html en un navegador.
4. Navegar entre las páginas mediante los enlaces.

También es posible utilizar Live Server
desde Visual Studio Code.

## 9. Limitaciones

El proyecto es un prototipo académico
desarrollado únicamente con HTML.

Los formularios no almacenan información.
No existe una base de datos conectada.
El inventario no se actualiza automáticamente.
Los reportes contienen datos ficticios.
